# GhostScout

AI-Powered Career Intelligence Agent

## Overview

GhostScout helps students understand their employability through AI-powered resume analysis, live job matching, skill-gap detection, learning recommendations, and personalized career roadmaps.

## Features

* Resume Analysis using Gemini
* Market Readiness Score
* Skill Gap Detection
* Learning Resource Recommendations
* Personalized Career Roadmaps
* Live Job Aggregation
* Opportunity Matching
* PDF Career Reports
* CLI Interface

## Tech Stack

Frontend:

* Next.js
* TypeScript
* TailwindCSS

Backend:

* FastAPI
* Gemini API
* ReportLab

Job Sources:

* Jobicy
* RemoteOK
* WeWorkRemotely
* Anakin Integrations

## Installation

### Backend

pip install -r requirements.txt

uvicorn main:app --reload

### Frontend

npm install

npm run dev
